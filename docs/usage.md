# 使いかた

[README に戻る](../README.md)

## アイコンと色

アイコンは馬の頭の形（シルエット）で、右下に状態の点がつきます。タスクバーが明るい色なら濃い色の馬、暗い色なら明るい色の馬になります。マウスを載せると、色の言葉と理由が出ます（Windows の決まりで 63 文字まで。詳しいことはメニューの状態の行に出ます）。

| 色 | 言葉 | トレイのふるまい |
| --- | --- | --- |
| 緑 | 動いています | 何もしません。サーバーの動いている時間をメニューに出します |
| 黄 | 確かめています | サーバーは答えますが、まだ正常ではありません（起動の途中や、JVLinkServer が JV-Link を立て直している間）。トレイは何もせず、JVLinkServer 本体が自分で立ち直るのを待ちます（本家の機能）。黄のまま 10 分続いたときだけ、一度作り直します |
| 赤（白い横棒） | 止まっています | サーバーが答えません。10 → 30 → 60 → 120 → 300 秒の間隔で起動し直します。緑が 10 分続くと、間隔は 10 秒に戻ります |
| 灰（輪） | 止めています | メニューで止めた状態です。起動し直しません |

赤になるのは、サーバーのプロセスが終わって答えないとき、または `UnreachableLimit` 回続けて答えないときです（起動してから `StartupGraceSeconds` の間は待ちます）。

次の赤は、起動し直しても直らないので、起動し直さずに理由を出します。直したら、メニューの「サーバーを起動する」で確かめ直します。

- 「JVLinkServer.exe が見つかりません」: ini の `ServerExe` を直します。
- 「片付けられないプロセスがあります」: 同じファイル名でパスを読めない JVLinkServer（ほかのユーザーのもの、管理者権限のもの）が動いています。そのプロセスを止めます。

## メニュー

アイコンを右クリックします。

- 状態の行: 状態と、サーバーの動いている時間（緑のとき）、ポート
- 「JV-Link の自動再起動 N 回 · 最後（…）」の行: JVLinkServer 本体が JV-Link を自動で再起動した回数と、最後の理由
- ログのフォルダを開く
- サーバーを作り直す（止まっているとき、起動できないときは選べません）
- サーバーを止める / サーバーを起動する
- 終了…（「JVLinkServer を止めて、終了します。よろしいですか？」と確かめます）

「サーバーを起動する」は、まず同じ EXE のパスで残っている JVLinkServer のプロセスをすべて止めてから起動します。手で起動した JVLinkServer も止まります。

同じファイル名でも、パスを読めないプロセス（ほかのユーザーのもの、管理者権限のもの）は止めません。その場合は赤で「片付けられないプロセスがあります」と出し、2つ目のサーバーは起動しません。

## トレイだけが終わるとき

- タスクスケジューラの「終了」や `Stop-ScheduledTask`、タスクマネージャーで終わらせるのはトレイだけで、サーバーは動き続けます。次に起動したトレイが引き継ぎます。サーバーを止めるときはメニューを使ってください。
- サインアウトや Windows の終了では、トレイは何もせずに終わります（終了を妨げません）。サーバーも同じセッションの中なので、Windows がまとめて終わらせます。

## ほかの PC から作り直す

ポートに届く相手なら、`POST /shutdown` を送れます。サーバーが終わると、トレイはそれを見て、20 秒ほどで起動し直します（続けて落ちているときは、上の表の間隔で延びます）。そのあと `--startup-delay-sec` の秒数ほど黄が続いてから、緑になります。

```sh
# Mac・Linux など
curl -X POST -d '' http://<Windows の PC>:8765/shutdown
```

```powershell
# Windows の PowerShell
Invoke-RestMethod -Method Post http://<Windows の PC>:8765/shutdown
```

curl では `-d ''`（空の本文）を付けてください。付けないと答えが返らず、待ち続けます。

JVLinkServer の `/shutdown` に認証はありません。ポートはファイアウォールなどで、信頼できる相手にだけ開けてください。

## 記録（ログ）

トレイは、`ServerArgs` の `--log-dir` のフォルダに `JVLinkServerTray_YYYYMMDD.log` を書きます。起動・引き継ぎ・色の変化・起こし直し・止めかたの各段・終了を1行ずつ書き、14 日より古いものは消します。メニューの「ログのフォルダを開く」で開けます。

## 決まりと制限

- 同じ EXE を2つ動かす使いかたは扱いません。
- EXE に署名がないので、ダウンロードしたものは初回に SmartScreen の警告が出ます（[入れかた](install.md#入れかた)の手順 2）。
- `ServerExe` が見つからないときは、赤で止まります。
- 同じファイル名でパスを読めないプロセスがあるときは、赤で止まります（上の「メニュー」を参照）。
